# Giallo Analitic

Interfaz de inteligencia deportiva para fútbol y futsal.

## Qué incluye

- Consultas a Giallo con input interactivo.
- Diseño responsive para escritorio y móvil.
- Fuentes verificadas: AFA, BeSoccer, Segundo Palo y biblioteca táctica.
- Indicadores de fecha de corte y verificación.
- Fondo animado LetterGlitch.

## Desarrollo local

```bash
npm install
npm run dev
```

La interfaz está preparada para conectar un backend de búsqueda multi-fuente que cite cada dato y verifique sus fechas.
